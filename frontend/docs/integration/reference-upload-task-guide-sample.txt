教案名称：七年级综合实践《校园垃圾分类与资源循环》

【一】基本信息
- 学段年级：初中七年级
- 学科：综合实践活动（可联动生物、地理、道德与法治）
- 课时安排：2课时（每课时40分钟）+ 1周课后实践
- 课型：项目化学习导入课 + 实践任务课

【二】教材与学情分析
1. 教材分析
本课聚焦“真实问题驱动”，以校园垃圾分类为情境，强调“知识理解-证据收集-方案设计-行动改进”的完整学习闭环。

2. 学情分析
七年级学生对垃圾分类有生活经验，但对分类标准、证据整理与方案论证能力较弱，适合通过小组协作完成结构化任务。

【三】教学目标
1. 知识与技能
- 识别四类垃圾（可回收物、有害垃圾、厨余垃圾、其他垃圾）及典型案例。
- 说明校园垃圾处理链条（投放、收集、运输、处理）的关键环节。

2. 过程与方法
- 使用观察、访谈、统计三种方法收集证据。
- 基于证据提出改进方案，并明确实施步骤与分工。

3. 情感态度与价值观
- 形成环保责任意识与公共参与意识。
- 在合作中学会倾听、协商与反思。

【四】教学重点与难点
- 教学重点：用真实证据支撑改进方案。
- 教学难点：将“发现问题”转化为“可执行的行动计划”。

【五】教学准备
- 教师准备：校园垃圾点位分布图、观察记录模板、访谈提纲模板、统计表模板。
- 学生准备：手机或相机、记录纸、分工表。

【六】教学过程（可直接用于生成作业任务）
环节1：情境导入（10分钟）
- 教师活动：展示校园常见错误投放照片，引导学生讨论“错在何处、影响是什么”。
- 学生活动：快速判断并说明理由。
- 阶段产出：问题清单（text）。

环节2：任务发布与分组（10分钟）
- 教师活动：发布项目任务“为学校提出可落地的垃圾分类改进方案”。
- 学生活动：4-6人分组，确定组长、记录员、访谈员、数据员。
- 阶段产出：小组分工表（document）。

环节3：证据采集指导（20分钟）
- 教师活动：示范观察记录、访谈提问、数据统计口径。
- 学生活动：完善本组采集计划（地点、对象、时间、工具）。
- 阶段产出：采集计划表（document）。

环节4：课后实践（1周）
- 任务A 观察记录：至少观察3个垃圾投放点，每点连续记录3次。
  - 产出：观察记录表（document）、现场照片（image）。
- 任务B 访谈调查：访谈至少2类对象（同学/教师/后勤）。
  - 产出：访谈纪要（document）、关键观点摘要（text）。
- 任务C 数据整理：统计主要错误类型与频次，制作图表。
  - 产出：统计表和图表（document/image）。

环节5：方案设计与展示（第2课时）
- 教师活动：提供“问题-原因-措施-验证”方案模板。
- 学生活动：形成2条以上改进措施并进行3分钟汇报。
- 阶段产出：改进方案书（document）、展示稿或海报（document/image/video）。

环节6：评价与反思（10分钟）
- 教师活动：组织同伴互评，指导学生复盘。
- 学生活动：提交个人反思与小组复盘。
- 阶段产出：反思记录（text/confirm）。

【七】作业设计（与系统“生成作业”目标对齐）
作业名称：校园垃圾分类改进行动计划
作业要求：
1. 必做：提交观察记录、访谈纪要、数据图表、改进方案书。
2. 选做：制作1份宣传材料（海报/PPT/短视频）。
3. 评分关注：证据完整性、数据真实性、方案可行性、协作与表达。

【八】评价量规（建议）
- 证据完整性（30%）：资料齐全、结构清晰。
- 证据质量（30%）：数据真实、来源明确、逻辑一致。
- 方案可行性（25%）：措施具体、责任明确、可验证。
- 展示与协作（15%）：表达清楚、分工合理、回应有效。

【九】板书/结构化提示（可提取为任务引导）
问题识别 -> 证据采集 -> 数据整理 -> 方案设计 -> 展示反馈 -> 行动复盘

【十】测试用途说明
本教案用于系统功能测试：上传“现成教学方案/教案”后，自动生成结构化作业任务引导与检查点。
